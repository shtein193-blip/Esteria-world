# Хроники Этерии — MVP

Первый прототип игры для Яндекс Игр:
- Fantasy RPG
- Match-3 поле 7×7
- Tower Defense
- волны врагов
- башня автоматически атакует
- Match-3 наносит дополнительный урон, лечит замок и даёт золото
- XP и уровни
- экран поражения

## Запуск

```bash
npm install
npm run dev
```

Открой адрес, который покажет Vite.

## Сборка

```bash
npm run build
```

Готовая игра будет в `dist/`.
