# Rescue Match — Stage 5 STABLE

Эта версия специально сделана без внешнего Phaser CDN: игра запускается как обычный статический HTML5-проект на Vercel/Netlify/локальном сервере.

## Реализовано
- 8×8 Match-3;
- 6 типов элементов;
- swap соседних клеток;
- проверка 3+ по горизонтали и вертикали;
- уничтожение;
- gravity + refill;
- cascades;
- 25 ходов;
- цель 12;
- desktop/mobile layout;
- пиратский фон и персонаж;
- fallback-рисование, если PNG не загрузится.

## Запуск
Можно просто открыть `index.html` через статический хостинг.

## Важно
Логика Match-3 теперь отделена от Phaser-зависимости. После подтверждения визуальной/игровой работы эту же логику перенесём обратно в production Phaser-сборку, а затем добавим Special Tiles.
