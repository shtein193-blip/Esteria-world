# Rescue Match — Stage 5 Vercel Fixed

Эта версия специально сделана для Vercel без внешних CDN и без обязательной загрузки JS/PNG по отдельным URL: игра и критические изображения встроены прямо в `index.html`.

## Как запускать
1. Загрузи содержимое этой папки в новый Vercel Project / GitHub repository.
2. Root Directory должен быть папкой, где лежит `index.html`.
3. Framework Preset: Other / None.
4. Build Command: пусто.
5. Output Directory: пусто.
6. Deploy.

Для обычного открытия `index.html` локально также работает.

## Важно
Новая модель пиратки с тентаклями уже встроена в игру как PNG с прозрачностью.
