# Rescue Match — Stage 5

Первый играбельный Match-3 прототип.

## Уже реализовано
- поле 8×8;
- 6 типов tiles;
- выбор двух соседних клеток;
- swap;
- отмена swap, если комбинации нет;
- поиск горизонтальных/вертикальных совпадений 3+;
- уничтожение;
- gravity;
- refill;
- каскады;
- 25 ходов;
- цель: уничтожить 12 элементов/единиц прогресса;
- адаптивный desktop/mobile layout;
- пиратский фон и персонаж из Stage 4 asset pack.

## Запуск
Требуется Node.js.

```bash
npm install
npm run dev
```

Затем открыть адрес Vite в браузере.
