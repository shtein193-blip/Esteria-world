# CLAW MARKET v0.1

Первый игровой прототип автомата с клешнёй.

## Запуск
Откройте index.html в браузере. Если браузер блокирует локальные изображения,
запустите любой простой локальный HTTP-сервер из этой папки, например:
python -m http.server 8000
и откройте http://localhost:8000

## Управление
- ← / A — влево
- → / D — вправо
- Space — схватить
- На телефоне — кнопки интерфейса

## Что уже есть
- один автомат;
- движение клешни;
- попытка за 20 монет;
- шанс успешного захвата;
- 20 призов;
- редкости и стоимость;
- инвентарь;
- продажа предметов;
- коллекция;
- сохранение прогресса в localStorage.
